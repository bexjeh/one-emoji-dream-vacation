One emoji standing in for a dream vacation — a single wordless postcard that makes a stranger want to book the flight.

## Run it

```sh
python3 main.py
```

Writes the emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./entry.txt` when the variable is unset).
